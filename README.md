# Nuria Sebastián Estudio

Prototipo web one page de Nuria Sebastián Estudio.

## Previsualización local

La web es estática y no necesita instalar dependencias. Basta con servir esta carpeta con cualquier servidor local.

```bash
python3 -m http.server 4173
```

Después, abrir `http://localhost:4173`.

## Publicación

El proyecto incluye un flujo de GitHub Pages. Cada cambio enviado a la rama `main` se publica automáticamente.

En GitHub, hay que activar **Settings → Pages → Source: GitHub Actions** una sola vez.
